# 彩票智投 · 手机版

大乐透 + 双色球（基础形态模型）与竞彩足球（澳客赔率研究）的手机网页预测工具。
纯静态站点，托管于 GitHub Pages，数据由 GitHub Actions 定时自动更新。

**在线地址**：`https://xiaomayi1899.github.io/lottery-tool/`

## 功能

### 数字彩（大乐透 / 双色球）
以**最近 50 期基础形态**为核心的分析引擎：

- **50 期走势图**：每号出号/遗漏网格（近 30 期），可视化冷热
- **频率与遗漏**：每号 50 期频次、当前遗漏、平均/最大遗漏，理论频次对照
- **和值**：50 期均值 ± σ 预测带，近 5 期趋势
- **奇偶 / 大小 / 质合**：50 期分布众数 → 下期形态预测
- **三分区**：区间均值与配额约束（大乐透 01-12/13-24/25-35；双色球 01-11/12-22/23-33）
- **跨度 / 连号 / 重号**：形态带约束与经验率修正
- **组合搜索**：在高分号码池中按全部形态约束枚举，输出主推 1 注 + 备选 3 注 + 小额复式参考，每项推荐逐项核对依据
- **后区独立评分**（频率 60% + 遗漏 40%）

### 竞彩足球
数据源：**中国竞彩网官方 API**（赛程/胜平负/让球赔率/排名）+ **澳客网**（百家欧赔初始/即时均值、平均凯利、升降赔统计、胜负指数及官方提点）。

单场研究流程（页面本地计算）：

1. 官方赔率去水 → 公平概率（含返还率展示）
2. 排名实力修正（联赛内排名差 → 温和概率平移）
3. 澳客百家均值对比 + 平均凯利（低凯利=庄家接受方向，高凯利=风险方向）
4. 澳客胜负指数（初始→最新，态度升降）+ 官方提点微加成
5. 赔率变化：官方快照序列 + 百家升降赔统计
6. 加权合成三向评分 → 推荐方向 + 置信度 + 理论 EV + 诱盘警示

汇总输出：**稳胆方向 / 串关参考（2 串 1）/ 价值搏冷 / 平局价值参考**。

> 为什么主推里几乎看不到「平」：主推取合成概率最高方向，而平局公平概率通常仅 25%~30%，几乎不会是三者最高——这是口径而非缺陷。平局赔率高，属价值型玩法，引擎按正期望（EV>0）单列「平局价值参考」，单场卡片中平局 EV>0 时也会有提示。

## 数据自动更新

`.github/workflows/update.yml`：每日北京时间 09:00 / 13:00 / 17:00 / 21:00 / 22:00 运行
（开奖后与竞彩盘口变化期覆盖），也可在 Actions 页面手动触发。

| 脚本 | 数据源 | 说明 |
| --- | --- | --- |
| `tools/update_lottery.py` | 福彩官网 / 体彩官网 | 双色球、大乐透开奖合并（保留 ~1200 期） |
| `tools/update_jingcai.py` | 竞彩官方 API + 澳客网 | 官方赔率为主，澳客增强数据任一失败自动降级 |
| `tools/update_status.py` | 本地 | 汇总 data/status.json 供页面状态栏 |
| `tools/build_embed.py` | 本地 | 把当前数据注入 index.html 作离线兜底（幂等） |

澳客网对自动化请求有 WAF 防护，抓取脚本已做慢速随机间隔与失败降级；增强数据缺失时页面仅用官方赔率+实力分析，并在“数据状态”页标注各源健康度。

## 页面数据加载

页面优先 `fetch('data/*.json')`（同源、带时间戳防缓存），失败时回落到内置快照（部署时由 `build_embed.py` 注入）。
